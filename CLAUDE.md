# MTCNA Quiz

MikroTik MTCNA cert quiz app. Two runtimes, one HTML source.

## Files

- `mtcna_web.py` — Flask app, port 5050, localhost only. Holds `HTML` (the whole SPA: inline `<style>` + `<script>` in a Python string) and the `/api/*` routes.
- `mtcna_web_network.py` — Flask app, port from `PORT` env / default, binds `0.0.0.0` for LAN/iPhone access. **Imports `HTML` directly from `mtcna_web.py`** via `importlib` — never duplicate markup here, edit `mtcna_web.py` only and this one follows automatically.
- `mtcna_quiz_standalone.html` — older, fully static, no-server version. Generated by `build_pwa.py` from `complete_all.json` + `mtcna_questions.json`. Out of sync with `mtcna_web.py`'s feature set (e.g. no chunked "po X" mode) — treat as a separate, simpler artifact, not a mirror.
- `mtcna_scraper.py` — Playwright scraper pulling questions from pass4future.com into JSON.
- `complete_all.json` / `mtcna_questions.json` / `indiatik_questions.json` — question banks. `indiatik_questions.json` is low quality (bad questions/answers) — `mtcna_web_network.py` excludes it via `EXCLUDED_SOURCES`; keep it excluded unless the source data is cleaned up.
- `progress.json` — per-source seen/session state, read/written by `/api/progress`.

## Editing rule

All quiz UI/logic lives in the `HTML` string inside `mtcna_web.py`. Edit it there. `mtcna_web_network.py` has no independent copy to keep in sync.

## Run

```
python3 mtcna_web.py            # localhost:5050
python3 mtcna_web_network.py    # LAN, for phone testing
```
